# История изменений

## 1.1.0

- Настройка автозапуска для текущего пользователя Windows.
- Фоновый запуск с сохраненной позой и ожиданием готовности Explorer.
- Обычный повторный запуск открывает настройки работающего экземпляра.
- Проверки регистрации автозапуска и команд с пробелами и Unicode.

## 1.0.1

- Исправлен черный фон вместо выбранного паркета.
- Проверенные BMP применяются через API обоев Windows и хранятся в постоянном каталоге тем.
- Физическая копия прежних обоев, восстановление и миграция старого фона.

## 1.0.0

- Первый Windows-порт на C#, WPF и Win32.
- Симуляция ткани, четыре ковра, свои картинки и три пола.
- Работа поверх настоящих значков, их сбор и восстановление координат.
- Настройки, значок в трее и сохранение положения ковра.
