# Ковер для Windows

Неофициальный перенос [siliconbag/under-the-rug](https://github.com/siliconbag/under-the-rug). Ковер с физикой ткани лежит поверх настоящих значков рабочего стола и под обычными окнами. Исходные текстуры и алгоритм ткани — из Mac-версии, интерфейс и интеграция с рабочим столом написаны для Windows.

## Запуск

Требования: Windows 10/11 **x64**, стандартный рабочий стол Проводника и .NET Framework 4.8 (входит в Windows 10 последних выпусков и Windows 11).

1. Распакуй весь архив `RugWindows-1.1.0-win-x64.zip`.
2. Открой папку `RugWindows` и запусти `RugWindows.exe`. Папку `Resources` оставь рядом с EXE.
3. Появятся ковер и настройки. Установка и права администратора не нужны.

Сборка не имеет цифровой подписи. Windows может показать предупреждение SmartScreen о неизвестном издателе. Исходники и скрипт сборки приложены отдельно для проверки и самостоятельной сборки.

## Управление

- Тяни ткань левой кнопкой: можно поднимать углы, складывать и переворачивать ковер. Отпусти кнопку — он упадет. Escape во время захвата отпускает ткань.
- Колесо над ковром поворачивает его. Правый клик открывает меню.
- За пределами ткани мышь работает с рабочим столом. Уже начатое перетаскивание значка проходит через ковер.
- В настройках доступны четыре исходных ковра, своя картинка (JPEG, PNG, BMP), размер, центрирование и повторное падение.
- Закрытие настроек оставляет ковер работать. Клик по значку в области уведомлений или повторный запуск EXE снова открывает настройки. Для завершения выбери «Выйти».
- Если экранов несколько, в настройках можно выбрать один экран для ковра.

## Автозапуск с Windows

В настройках включи «Запускать вместе с Windows». Ковер будет появляться после входа в твою учетную запись с сохраненными размером, текстурой и положением. Окно настроек при этом не открывается. Если Проводник еще не создал рабочий стол, приложение подождет в фоне.

Настройки всегда доступны из значка в трее или при обычном повторном запуске EXE. Отключить автозапуск можно той же галочкой. Права администратора не требуются. Оставь папку программы на месте; если перенесешь ее, запусти EXE вручную, чтобы обновить путь автозапуска.

Перед удалением программы отключи автозапуск в настройках. Команды для управления без открытия окна: `RugWindows.exe --enable-startup` и `RugWindows.exe --disable-startup`. Ключ `--startup` запускает ковер в фоне и используется Windows автоматически.

## Значки и обои

«Замести под ковер» собирает значки в кучу. **Перед первым перемещением** приложение сохраняет исходные координаты на диск. «Разложить обратно» возвращает их; восстановление доступно и после перезапуска. Повторное сметание не заменяет исходную копию. Приложение не перемещает файлы на диске, не удаляет их и не меняет содержимое.

Для сметания и точного восстановления выключи **два пункта** в контекстном меню рабочего стола: «Вид → Упорядочить значки автоматически» и «Вид → Выровнять значки по сетке». Приложение само эти настройки не меняет. Сетка Windows округляет позиции и раздвигает соседние значки, поэтому при включенной сетке операция блокируется **до перемещения значков** и показывает подсказку. Физика ковра работает при любых настройках значков. Пока значки скрыты, чтение и перемещение недоступны. При удалении или переименовании значков копия сохраняется для последующей попытки восстановления; восстановление сравнивает подпись и номер одноименного значка. Если расположение мониторов изменилось, координаты могут потребовать ручной корректировки.

Выбор пола меняет обои Windows. Изображение полностью проверяется и сохраняется в совместимый непрозрачный BMP, затем применяется через современный API обоев Windows с проверкой результата. Путь прежних обоев, физическая копия изображения и режим размещения сохраняются; кнопка «Вернуть прежние обои» восстанавливает их. Для сложных конфигураций с разными обоями на мониторах и слайд-шоу Windows используется обычный общий фон: вся конфигурация слайд-шоу не архивируется.

В версии 1.0.1 исправлен черный фон вместо паркета. Уже выбранный в версии 1.0 пол автоматически исправляется при следующем запуске. Первоначальная копия прежних обоев сохраняется при переключении между полами.

Настройки, импортированные картинки, журнал и резервная копия координат хранятся в `%LOCALAPPDATA%\UnderTheRugWindows`. Готовые обои и копии прежнего фона — в `%APPDATA%\Microsoft\Windows\Themes\UnderTheRugWindows`, чтобы оболочка Windows могла их прочитать. Программа работает локально, не обращается к сети; автозапуск включается пользователем в настройках. Перед удалением программы отключи автозапуск и при необходимости верни расположение значков и обои через настройки. Для удаления достаточно закрыть приложение и удалить его папку; пользовательские данные хранятся отдельно.

## Отличия и ограничения

Swift/AppKit/Metal заменены на C#/WPF/Win32. Физика перенесена, но освещение и мягкая тень адаптированы для WPF: пиксельного совпадения с шейдерами Metal нет. Сетка использует 32 столбца вместо 44. При покое цикл физики и отрисовки останавливается, остаются таймер наведения мыши и проверка значков раз в 4 секунды.

Поддерживается стандартная оболочка Explorer. Программы замены рабочего стола и сторонние менеджеры значков могут быть несовместимы. Встроенные классы окон Explorer не являются стабильным публичным API; после крупных обновлений Windows интеграция может потребовать корректировки. Восстановление после перезапуска Explorer выполняется при следующей проверке рабочего стола. Сборка рассчитана на x64, не на 32-разрядную Windows или ARM64 Explorer.

## Сборка из исходников

В PowerShell из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -Package
```

Скрипт использует системный C#-компилятор .NET Framework, не скачивает пакеты и не требует Visual Studio. Результат: `release\RugWindows\RugWindows.exe`, архив программы и архив исходников рядом. Файлы ресурсов берутся из приложенного исходного каталога `original\under-the-rug-main\Resources` либо из `Resources` рядом со скриптом. Для дополнительных нативных тестов добавь `-NativeTests`: они работают с отдельным невидимым тестовым списком значков и не трогают рабочий стол пользователя.

Служебные режимы:

```powershell
.\release\RugWindows\RugWindows.exe --diagnose diagnostics.txt
.\release\RugWindows\RugWindows.exe --render-demo demo.png
.\release\RugWindows\RugWindows.exe --smoke-test smoke-report.txt
```

`--diagnose` читает состояние оболочки, не перемещая значки. `--render-demo` сохраняет кадр со складкой без изменения рабочего стола. `--smoke-test` на 9 секунд запускает настоящее приложение, сохраняет диагностический отчет и изображения своих окон, затем выходит. Значки он не перемещает; обычная миграция старого фона и обновление ранее включенного автозапуска при смене пути остаются активны. Запускай его из постоянной папки программы при закрытом основном экземпляре. Для изолированных проверок без изменений пользовательских настроек используй `build.ps1 -Test`.
